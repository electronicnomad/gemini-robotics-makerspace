# robot_controller.py 오도메트리 설정 정리

작성일: 2026-07-13

## 1. 오도메트리 조정 변수 항목

### 1.1 마스터 스위치 (30줄, 모듈 레벨)

| 변수 | 현재 값 | 의미 |
|---|---|---|
| `ODOMETRY_SAFETY_ENABLED` | **False** | 경계 판정·불확실성 fail-safe 전체 on/off. **현재 꺼져 있음** (바닥 테스트용). 좌표 적분 자체는 이 값과 무관하게 항상 동작. 테이블에 올릴 땐 True로 |

### 1.2 속도 캘리브레이션 (60~61줄) — 오도메트리 정확도의 핵심

| 변수 | 현재 값 | 의미 |
|---|---|---|
| `SPEED_LINEAR` | 260.0 mm/s | 전/후진 속도. **실측 반영됨** (2026-07-12, 전진 1.5초에 약 39cm) |
| `SPEED_ANGULAR` | 22.5 deg/s | 회전 속도. **실측 반영됨** (2026-07-13, "토토 돌아" 4초에 90도 회전) |

### 1.3 물리 치수 (64~68줄)

| 변수 | 현재 값 | 의미 |
|---|---|---|
| `ROBOT_WIDTH` | 180.0 mm | 로봇 좌우 폭 (경계 계산 시 몸체만큼 안쪽으로 한계 축소, 실측 반영) |
| `ROBOT_LENGTH` | 320.0 mm | 로봇 앞뒤 길이 (실측 반영) |
| `TABLE_WIDTH` | 1200.0 mm | 테이블 가로 (X축 ±600, 중앙 원점) |
| `TABLE_DEPTH` | 800.0 mm | 테이블 세로 (Y축 ±400, 시작 시 로봇이 바라보는 방향) |
| `SAFETY_MARGIN` | 50.0 mm | 가장자리 추가 여유. 보수적으로 하려면 키움 |

### 1.4 드리프트 불확실성 / fail-safe (78~80, 84줄)

| 변수 | 현재 값 | 의미 |
|---|---|---|
| `UNCERTAINTY_PER_MM` | 0.04 | 이동 1mm당 누적 오차 추정 (4%). 누적될수록 안전영역이 좁아짐 |
| `UNCERTAINTY_PER_DEG` | 0.25 mm/도 | 회전 1도당 누적 오차. 회전이 잦은 이 로봇에선 누적 주범 — re-home이 너무 잦으면 낮춤 |
| `UNCERTAINTY_LIMIT` | 250.0 mm | 이 값을 넘으면 추정 불신 → 정지 + 재중앙화(re-home) 요청 |
| `SAFETY_SPEED_FACTOR` | 1.15 | 경계 예측 시 속도를 15% 부풀려 보수적으로 판정 |

### 1.5 시작 자세 (초기 상태, 54줄 및 `reset_odometry` 기본값)

- `x=0, y=0, theta=90` — **테이블 중앙에서 +Y 방향을 보고 시작**하는 게 전제. 대시보드 Reset도 이 자세로 리셋하므로, 리셋 시 로봇을 물리적으로 중앙·정방향에 놓아야 한다.

### 1.6 우선순위 조언

(2026-07-13 갱신) 속도 2종 캘리브레이션 완료. 현재 권장 구성은 "차단형 펜스" 대신:

1. `ODOMETRY_SAFETY_ENABLED = False` 유지 (차단식 소프트 펜스 비활성)
2. `EDGE_CAUTION_ENABLED = True` — 라인 근처(150mm)에서 전진 펄스 감속
3. 로보로보 라인 반사 + BCM 24 피드백(협조 양보 + 위치 앵커)이 실제 경계를 담당
   (상세: docs/line-sensor-feedback-wire.md)

## 2. 로봇 크기 설정

로봇 크기는 `robot_controller.py` 64~65줄에 입력되어 있다:

| 변수 | 현재 값 | 의미 |
|---|---|---|
| `ROBOT_WIDTH` | 180.0 mm | 좌우 폭 (좁은 쪽, 실측 반영) |
| `ROBOT_LENGTH` | 320.0 mm | 앞뒤 길이 (긴 쪽, 실측 반영) |

### 어디에 쓰이나

`get_bounds_at_heading()`의 경계 계산에서만 사용된다. 좌표는 로봇 **중심** 기준이므로, 현재 헤딩(theta)에 따라 몸체가 차지하는 범위를 계산해 그만큼 테이블 한계를 안쪽으로 당긴다 — 예를 들어 로봇이 가로로 누워 있으면 X방향으로 125mm(길이의 절반)만큼 더 여유를 둔다. 회전각에 따라 동적으로 계산되므로 대각선 자세도 반영된다.

### 참고사항

- **높이는 모델링하지 않는다** (2D 평면 경계만).
- 이 값은 `ODOMETRY_SAFETY_ENABLED`가 True일 때만 실제 효과가 있다 (현재 False라 지금은 미사용).
- 값이 실물과 다르면 경계 판정이 어긋난다 — 너무 작게 입력하면 몸체 일부가 가장자리 밖으로 나가고도 안전하다고 판단할 수 있다.

### 확인 필요

2026-07-13 실측 반영 완료: 가로 180mm x 세로 320mm. 방향 기준은 "WIDTH = 좌우(진행 방향의 직각), LENGTH = 앞뒤(진행 방향)".
