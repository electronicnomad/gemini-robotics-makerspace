라즈베리 파이 4: 자동 스크립트 백업 및 쓰기 문제 해결 가이드

1. 자동 설정 백업 스크립트
--------------------------------------------------------------------------------
시스템을 읽기 전용(Read-Only) 상태로 잠그기 전에, 주요 설정 스크립트를 외부 매체
(보조 USB 플래시 드라이브 또는 네트워크 저장소 공유 폴더)로 백업하는 것이 좋습니다.

* 백업 스크립트 파일 생성:
  $ vi /home/pi/backup_configs.sh

* 다음 코드를 파일에 붙여넣기:
  #!/bin/bash
  # 백업 대상 디렉토리 정의 (마운트된 백업 드라이브 경로로 수정)
  BACKUP_DIR="/mnt/backup_drive/pi_power_project"
  mkdir -p "$BACKUP_DIR"

  # 주요 설정 및 자동화 파일 복사
  cp /boot/firmware/config.txt "$BACKUP_DIR/config.txt.bak" 2>/dev/null || cp /boot/config.txt "$BACKUP_DIR/config.txt.bak"
  cp /etc/rc.local "$BACKUP_DIR/rc.local.bak"
  cp /home/pi/battery_monitor.sh "$BACKUP_DIR/battery_monitor.sh.bak"

  echo "시스템 설정이 $BACKUP_DIR 경로로 성공적으로 백업되었습니다."

* 스크립트에 실행 권한 부여:
  $ chmod +x /home/pi/backup_configs.sh

* 오버레이 파일시스템을 활성화하기 전에 수동으로 언제든지 실행:
  $ /home/pi/backup_configs.sh


2. 파일 저장 에러 문제 해결 (읽기 전용 에러)
--------------------------------------------------------------------------------
파일을 저장하거나 설정을 변경하려 할 때 "Read-only file system" 또는 "Permission denied"
에러가 발생하면, 오버레이 시스템이 활성화되어 있거나 안전하지 않은 종료로 인해 
파일시스템이 자동으로 읽기 전용으로 마운트된 것입니다.

* 증상: vi 편집기에서 "[ Error writing ...: Read-only file system ]" 또는 "E45: 'readonly' option is set" 표시
* 증상: touch 또는 mkdir 명령어가 즉시 실패함

* 빠른 해결책 1: 긴급 임시 쓰기 권한 확보 (재부팅 없이 적용)
  저장 장치 자체가 raspi-config에 의해 완전히 잠긴 것이 아니라 OS 파티션이
  고정된 경우, 실시간 재마운트를 강제 실행합니다:
  $ sudo mount -o remount,rw /

* 빠른 해결책 2: 파일시스템 저널 정리
  배터리가 비정상적으로 끊어져 파일 매핑이 일부 손상된 경우, 커널은 추가 손상을
  방지하기 위해 드라이브를 잠급니다. 파일시스템 검사를 강제 실행합니다:
  $ sudo umount /dev/mmcblk0p2
  $ sudo fsck -y /dev/mmcblk0p2
  (참고: 시스템 파티션이 사용 중인 경우 'sudo touch /forcefsck' 명령을 실행하고
  재부팅하면 부팅 과정에서 안전하게 파일시스템 검사가 진행됩니다.)


3. 배포 전 점검 체크리스트
--------------------------------------------------------------------------------
모니터/키보드를 분리하고 라즈베리 파이를 배터리만으로 구동하기 전에 점검할 사항:

[ ] 1. 카메라를 로컬에서 실행하여 리본 케이블 결선 상태 확인.
[ ] 2. 라즈베리 파이가 목적지 Wi-Fi 액세스 포인트에 자동으로 연결되는지 확인.
[ ] 3. 백업 스크립트를 실행하여 텍스트 설정 파일들을 안전하게 복사.
[ ] 4. raspi-config를 통해 오버레이 파일시스템을 활성화하고 재부팅.
[ ] 5. 구동 중 전원 코드를 강제로 뽑은 후 다시 부팅하여 손상 경고 없이
       시스템이 즉시 복구되는지 테스트.
