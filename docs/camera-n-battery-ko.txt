라즈베리 파이 4: LIBCAMERA 스트리밍, 자동화 및 배터리 구동 시간 계산

1. LIBCAMERA 스트리밍 아키텍처
--------------------------------------------------------------------------------
최신 라즈베리 파이 OS 버전은 libcamera 프레임워크를 사용하여 이미지 처리 작업을
VideoCore 하드웨어 ISP로 위임하므로 CPU 점유율을 0%에 가깝게 유지합니다.

* 카메라 센서 인식 여부 확인:
  $ libcamera-hello --list-cameras

* 저전력 최적화 네트워크 스트림 실행 (TCP 기반 720p @ 15fps):
  $ rpicam-vid -t 0 --inline --listen -o tcp://0.0.0.0:5000 --width 1280 --height 720 --framerate 15

  플래그 상세 설명:
  -t 0            : 타임아웃 없이 무한히 실행.
  --inline        : 중간에 접속하는 클라이언트를 위해 모든 프레임에 스트림 헤더 포함.
  tcp://0.0.0.0   : 모든 네트워크 인터페이스에서 5000번 포트 수신 대기.

* 외부 컴퓨터의 VLC 미디어 플레이어에서 스트림 시청:
  1. VLC 실행 -> 미디어 -> 네트워크 스트림 열기 (Ctrl+N)
  2. 네트워크 URL 입력: tcp://<라즈베리파이_IP_주소>:5000
  3. 재생 클릭.


2. 부팅 시 자동 실행 설정 (/etc/rc.local)
--------------------------------------------------------------------------------
부팅 시 Wi-Fi 전력 최적화를 적용하고 헤드리스(Headless) 상태로 카메라 스트림을 자동 가동하려면:

* 시스템 부팅 스크립트 열기:
  $ sudo vi /etc/rc.local

* 기존 USB 연결 해제(unbind) 명령어 및 마지막 'exit 0' 줄 바로 위에 다음 블록 추가:

  # --- Wi-Fi 전력 최적화 ---
  # 데이터 프레임 전송 사이 간격에 Wi-Fi를 잠깐 절전 상태로 전환
  iwconfig wlan0 power on

  # --- 자동 저전력 카메라 스트림 ---
  # 백그라운드에서 헤드리스로 스트림을 실행하고 출력을 null로 리다이렉트
  rpicam-vid -t 0 --inline --listen -o tcp://0.0.0.0:5000 --width 1280 --height 720 --framerate 15 > /dev/null 2>&1 &


3. 배터리 구동 시간 계산
--------------------------------------------------------------------------------
슬림하게 최적화된 약 300mA 전류 소비량(5V 기준)을 바탕으로, 일반적인 3.7V 소비자용
보조배터리 사용 시 구동 시간을 계산합니다 (표준 74% 승압 효율 적용):

계산 공식:
  실제 사용 가능 용량 (5V 기준) = 보조배터리 표기 mAh * 0.74
  구동 시간 (시간) = 실제 사용 가능 용량 / 300mA

예상 구동 시간:
* 5,000 mAh 배터리  : 약 3,700 mAh 실제 사용 -> 약 12.3 시간
* 10,000 mAh 배터리 : 약 7,400 mAh 실제 사용 -> 약 24.6 시간
* 20,000 mAh 배터리 : 약 14,800 mAh 실제 사용 -> 약 49.3 시간


4. 배터리 위험 상태 안전 종료 스크립트
--------------------------------------------------------------------------------
하드웨어 전원이 완전히 끊기기 전에 라즈베리 파이 내부 전압 임계값을 모니터링하여
운영체제를 안전하게 종료합니다.

* 모니터링 스크립트 생성:
  $ vi /home/pi/battery_monitor.sh

* 다음 코드 붙여넣기:
  #!/bin/bash
  # 커널에 저전압 이벤트가 기록되었는지 확인 (< 4.63V)
  if dmesg | grep -q "Under-voltage detected"; then
      echo "배터리 위험 상태! 안전 종료를 시작합니다."
      sudo shutdown -h now
  fi

* 스크립트에 실행 권한 부여:
  $ chmod +x /home/pi/battery_monitor.sh

* cron을 사용하여 5분마다 실행되도록 스케줄링:
  $ crontab -e
  가장 아래에 다음 줄 추가:
  */5 * * * * /bin/bash /home/pi/battery_monitor.sh
