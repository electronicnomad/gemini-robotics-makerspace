1. LIBCAMERA STREAMING ARCHITECTURE
--------------------------------------------------------------------------------
Modern Raspberry Pi OS versions use the libcamera framework, offloading image
processing to the VideoCore hardware ISP and keeping CPU usage near 0%.

* Verify the camera sensor is detected:
  $ libcamera-hello --list-cameras

* Launch a low-power, optimized network stream (720p @ 15fps over TCP):
  $ rpicam-vid -t 0 --inline --listen -o tcp://0.0.0.0:5000 --width 1280 --height 720 --framerate 15

  Flags Explained:
  -t 0            : Runs indefinitely without timing out.
  --inline        : Includes stream headers in every frame for mid-stream clients.
  tcp://0.0.0.0   : Opens listening port 5000 on all network interfaces.

* View the stream on an external computer via VLC Media Player:
  1. Open VLC -> Media -> Open Network Stream (Ctrl+N)
  2. Enter network URL: tcp://<YOUR_PI_IP_ADDRESS>:5000
  3. Click Play.


2. AUTOMATION ON BOOT (/etc/rc.local)
--------------------------------------------------------------------------------
To automate Wi-Fi power-saving and headlessly launch the camera stream on boot:

* Open the system boot script:
  $ sudo nano /etc/rc.local

* Append the following blocks directly ABOVE your previous USB unbind line 
  and the final 'exit 0' line:

  # --- Wi-Fi Power Optimization ---
  # Force Wi-Fi to sleep briefly between data frame transmissions
  iwconfig wlan0 power on

  # --- Automated Low-Power Camera Stream ---
  # Runs the stream headlessly in the background, routing outputs to null
  rpicam-vid -t 0 --inline --listen -o tcp://0.0.0.0:5000 --width 1280 --height 720 --framerate 15 > /dev/null 2>&1 &


3. BATTERY RUNTIME CALCULATIONS
--------------------------------------------------------------------------------
At a lean ~300mA current draw baseline (5V), calculate runtime using standard 
3.7V consumer power banks (assuming a standard 74% step-up efficiency factor):

Formula:
  Actual Usable Capacity (at 5V) = Stated Power Bank mAh * 0.74
  Runtime (Hours) = Actual Usable Capacity / 300mA

Estimated Runtimes:
* 5,000 mAh Bank  : ~3,700 mAh usable -> Approx 12.3 Hours
* 10,000 mAh Bank : ~7,400 mAh usable -> Approx 24.6 Hours
* 20,000 mAh Bank : ~14,800 mAh usable -> Approx 49.3 Hours


4. BATTERY CRITICAL SAFE SHUTDOWN SCRIPT
--------------------------------------------------------------------------------
Monitor the Pi's internal voltage threshold to safely halt the operating system
before hardware power cuts completely out.

* Create the monitor script:
  $ nano /home/pi/battery_monitor.sh

* Paste the following code:
  #!/bin/bash
  # Check if the kernel has flagged an under-voltage event (< 4.63V)
  if dmesg | grep -q "Under-voltage detected"; then
      echo "Battery critical! Initiating safe power-down."
      sudo shutdown -h now
  fi

* Make the script executable:
  $ chmod +x /home/pi/battery_monitor.sh

* Schedule it to check every 5 minutes using cron:
  $ crontab -e
  Add this line at the bottom:
  */5 * * * * /bin/bash /home/pi/battery_monitor.sh
