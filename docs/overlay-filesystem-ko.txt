================================================================================
라즈베리 파이 4: 읽기 전용 오버레이 파일시스템 (OVERLAYFS)
================================================================================

1. 오버레이 파일시스템 작동 원리
--------------------------------------------------------------------------------
기본 오버레이 파일시스템(overlayfs)을 활성화하면 물리 microSD 카드가 엄격한
읽기 전용(Read-Only) 상태로 잠깁니다.

* 모든 로그, 임시 파일 및 시스템 수정 사항은 라즈베리 파이의 휘발성 RAM 내부에서
  구동되는 가상 레이어로 리다이렉트됩니다.
* 스트리밍 중 배터리가 갑자기 방전되거나 전원 코드가 뽑히더라도, 물리 저장 장치에
  데이터가 쓰여지지 않으므로 파일 손상이 전혀 발생하지 않습니다.
* 재부팅 시 RAM 오버레이 레이어가 완전히 초기화되어 라즈베리 파이가 깨끗한
  초기 설정 상태로 복원됩니다.


2. 단계별 활성화 절차
--------------------------------------------------------------------------------
이 레이어를 구성하는 가장 안전한 방법은 내장 시스템 유틸리티를 이용하는 것입니다:

1. 터미널에서 유틸리티 실행:
   $ sudo raspi-config

2. 키보드 방향키를 사용하여 이동:
   -> 4 Performance Options (엔터 누름)

3. 아래로 스크롤하여 선택:
   -> P3 Overlay File System (엔터 누름)

4. 프롬프트 표시 시: "Would you like the overlay file system to be enabled?"
   -> <Yes> 선택 (엔터 누름)

5. 프롬프트 표시 시: "Would you like the boot partition to be write-protected?"
   -> <Yes> 선택 (엔터 누름)

6. <Finish>로 이동하여 메뉴를 빠져나오고 시스템 재부팅 요청을 승인합니다.


3. 추후 영구적인 시스템 변경 적용 방법
--------------------------------------------------------------------------------
저장 장치가 잠겨 있으므로 오버레이가 구동되는 동안 변경한 모든 사항은 재부팅 시 삭제됩니다.
파일, 스크립트 또는 Wi-Fi 설정을 영구적으로 수정하려면:

1. 쓰기 잠금을 임시로 해제:
   $ sudo raspi-config
   -> 4 Performance Options -> P3 Overlay File System -> <No> 선택
   -> Disable boot partition write-protection -> <No> 선택

2. 시스템 재부팅:
   $ sudo reboot

3. 일반적인 업데이트, 스크립트 수정 또는 시스템 유지보수 작업 수행.

4. 2절의 단계를 다시 반복하여 파일시스템을 안전한 저전력 배포 모드로 다시 잠급니다.
