================================================================================
RASPBERRY PI 4 POWER OPTIMIZATION SUMMARY
================================================================================

1. CORE GOAL & BENCHMARK REACHED
--------------------------------------------------------------------------------
Objective: Reduce Raspberry Pi 4 current draw by ~1.0 Amp (1,000mA) while keeping
           Wi-Fi functionality fully active for a wireless streaming setup.

Strategy:  Replace a high-draw USB Webcam with an official CSI Ribbon Camera,
           offload CPU decoding workloads to the hardware ISP, and completely 
           power down the USB controller alongside unused wireless and audio components.

Expected Baseline: An idling Pi 4 draws ~540mA-600mA. With these optimizations
                   active during camera streaming, current draw drops to a 
                   hyper-efficient ~250mA - 350mA total.


2. COMPONENT SAVINGS BREAKDOWN
--------------------------------------------------------------------------------
* USB Webcam -> CSI Ribbon Camera:   Saves 300mA - 700mA 
  - Hardware: Saves ~150mA shifting from USB to the efficient CSI bus.
  - CPU Offload: Saves 150mA-550mA shifting video logic away from the ARM cores.
* Turning Off All USB Ports:         Saves 300mA - 400mA
* Turning Off Onboard Audio:         Saves 50mA
* Turning Off Both HDMI Ports:       Saves 60mA
* Turning Off Bluetooth:             Saves 20mA
* Enabling Wi-Fi Power Save Mode:    Saves 30mA - 50mA

TOTAL CURRENT SAVED:                 670mA to 1,170mA (Hits the 1A Target)


3. CONFIGURATION FILE MODIFICATIONS (/boot/firmware/config.txt)
--------------------------------------------------------------------------------
Open configuration file:
$ sudo vi /boot/firmware/config.txt
(Note: Use /boot/config.txt on older OS versions)

Append the following lines to disable onboard components and underclock limits:

# --- Power Optimization Configurations ---
dtoverlay=disable-wifi     # (Omit this if keeping Wi-Fi active)
dtoverlay=disable-bt       # Disable Bluetooth
dtparam=audio=off          # Disable Onboard Audio
hdmi_blanking=2            # Deep cut power to HDMI transmission hardware
dtparam=pwr_led_trigger=none  # Disable Power LED
dtparam=act_led_trigger=none  # Disable Activity LED

# --- Optional Safe Underclocking (Lowers peak power limits) ---
arm_freq=1000
gpu_freq=250
over_voltage=-2


4. BOOT AND RUNTIME COMMANDS (/etc/rc.local & Shell)
--------------------------------------------------------------------------------
To completely disable the physical VL805 USB 3.0 controller chip and optimize
Wi-Fi runtime power, execute or automate the following commands:

* Turn off video output immediately via terminal:
  $ sudo /usr/bin/tvservice -o

* Turn on Wi-Fi Power Saving Mode (briefly sleeps when idle):
  $ sudo iwconfig wlan0 power on

* Automate Complete USB Shutdown on Boot:
  Open system boot script:
  $ sudo vi /etc/rc.local

  Add this exact line directly ABOVE the 'exit 0' line:
  echo '1-1' | tee /sys/bus/usb/drivers/usb/unbind


5. SYSTEM FIRMWARE & VERIFICATION
--------------------------------------------------------------------------------
Ensure the bootloader is running optimized power-management firmware:
$ sudo rpi-eeprom-update
$ sudo rpi-eeprom-update -d -a

Verify that the USB bus is entirely dead after rebooting:
$ lsusb
(If successful, it returns an empty list or an error indicating no USB buses found.)
