10,000mAh 보조배터리 구성 전원 사양서 (태양광 제외)
================================================================================

1. 구동 시간 용량 분석
--------------------------------------------------------------------------------
태양광 충전 없이 10,000mAh 배터리 팩만 사용할 경우, 전체 구동 시간은
전력 절감 조치의 효율성에 전적으로 의존합니다.

* 총 사용 가능 에너지 (내부 3.7V 셀 기준): 37.0 와트시 (Wh)
* 표준 5V 승압 변환기(Boost Converter) 효율 : 약 74%
* 순 실제 출력 용량 (5V 기준)                : 약 7,400 mAh

시스템 구성별 예상 구동 시간:

* 최적화 구성 (CSI 카메라, USB 차단, 오디오/BT 차단, Wi-Fi 절전 모드):
  - 전류 소비량: 약 300 mA (1.5 와트)
  - 예상 구동 시간: 약 24.6 시간 (하루 연속 구동 가능)

* 미최적화 구성 (기존 USB 웹캠, CPU 높은 점유율, USB 버스 활성화):
  - 전류 소비량: 약 1,200 mA (6.0 와트)
  - 예상 구동 시간: 약 6.1 시간


2. 배터리 선택 기준 (확인할 기술 요건)
--------------------------------------------------------------------------------
태양광 패널로 전력을 지속적으로 보충하지 않으므로, 선택한 10,000mAh 보조배터리가
다음 기술 요구 사항을 충족하는지 확인하세요:

* 최소 출력 전류: 단일 USB-C 포트에서 최소 5V / 3.0A (15와트) 출력을 지원해야 합니다.
  5V / 2.1A와 같이 낮은 출력 제한은 대역폭이 높은 Wi-Fi 전송 순간에
  저전압 쓰로틀링(Undervoltage)을 유발할 수 있습니다.
* 패스스루 충전(Pass-Through Charging): 방전(사용)과 동시에 충전을 지원하는
  보조배터리를 선택하세요. 이렇게 하면 실시간 스트리밍 중단 없이 벽면 콘센트에
  배터리를 연결하여 충전할 수 있습니다.
* 자동 전원 켜짐(Auto-On): 기기가 연결되면 버튼을 누르지 않아도 자동으로 전력을
  공급하는 보조배터리를 사용하세요. 버튼을 직접 눌러야 하는 경우 무인 임베디드
  환경에서 관리가 어려워질 수 있습니다.


3. 배포 및 유지보수 주기
--------------------------------------------------------------------------------
폐쇄형 배터리 시스템이므로 다음과 같이 교체 주기를 관리하세요:

* 일일 교체: 저전압 감지 스크립트에 의해 안전 종료가 실행되기 전 안전 마진을
  보장하기 위해 20~22시간마다 배터리 교체 또는 충전 시간을 일정에 반영하세요.
* 안전한 교체: 전원이 즉시 꺼지는 상태에서 핫스왑을 시도하지 마세요. 앞서 설정한
  읽기 전용 오버레이 파일시스템 덕분에 방전된 배터리를 뽑고 새 배터리를 꽂으면
  라즈베리 파이가 디스크 에러 없이 안전하게 부팅되어 스트리밍 상태로 복귀합니다.
